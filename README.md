# tubelocalbread-releases

Builds of **TubeLocalBread**, a personal app that is sideloaded with SideStore. This repo only hosts
the latest unsigned `Tube.ipa`, its icon and a SideStore/AltStore source file, served by GitHub Pages.
It is overwritten automatically by CI on every build (one commit, no history).

SideStore source URL:

    https://bouncybread.github.io/tubelocalbread-releases/source.json

Add it in SideStore → **Sources** → **+**. The app's source code is not in this repo.
